About the course

ISOM 472 is the MIS capstone. Teams build and deploy a working information system for a real client, using an AI coding agent to write code under the team's direction. Planning and design are done in Gemini Enterprise, the system is built in Antigravity, the code and its history live in GitHub, and the data and sign-ins run on Supabase. Work is delivered in stages across the semester, and the finished system runs at a public address that anyone can open.
