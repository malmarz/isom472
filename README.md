# isom472

Companion website for ISOM 472, Project in Information Systems (Fall 2026/2027),
College of Business Administration, Kuwait University. It is a small set of
static HTML pages with one shared stylesheet and no build step. The site
publishes from the repository root via GitHub Pages and is served at
<https://malmarz.github.io/isom472/>; the `.nojekyll` file keeps the files
serving verbatim.
