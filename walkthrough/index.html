Your first change, twice

The same small change — once by hand, once with Antigravity.

ISOM 472 › Your first change

Do this once by hand before you let an agent do it. Not because the manual way is better — because when the agent does something strange in week 7, you need to know what it was supposed to do.

The task, both times: add your own name to the team table in README.md. It is one line. The point is the loop around it, not the change.

Before either route

  • Accept the invitation to your repository. It is in your email and in your GitHub notifications. Until you accept, nothing you do can be pushed.
  • Tell git who you are. If the email on your commits is not on your GitHub account, GitHub cannot tell the commit is yours, and work it cannot see does not count towards your individual mark. The steps are in docs/setup.md in your own repository.

Route A — by hand, with GitHub Desktop

The full version of this, with screenshots of every button, is on publishing from your repository. In short:

  1. Clone the team repository so it is a folder on your laptop.
  2. Create a branch. Name it after what you are doing: add-fatima-to-readme.
  3. Edit README.md in any editor. Add your name to the table.
  4. Commit with a message that says what changed: docs(readme): add Fatima to the team table.
  5. Publish the branch, then open a pull request.
  6. Ask a teammate to review it. They open Files changed › Review changes, write what they checked, and choose Approve.
  7. Merge. Your change is now part of main.

You cannot push straight to main — GitHub refuses it. Every change goes through a branch, a pull request and somebody else's approval. That is set once for every team repository and it is not a fault in your setup.

Route B — with Antigravity

Open the same folder in Antigravity. Everything below happens in the chat panel, with the repository open.

1. Tell it what it is looking at

Your repository contains a file called AGENTS.md. Antigravity reads it, and it already says how this course works: the commit format, the comment rules, the fact that it may commit but must not push, merge, tag or open pull requests. You do not need to repeat any of that.

2. Ask for the change

Add me to the team table in README.md. My name is Fatima and my
standing role is Client Lead.

Make a branch named after the change first. Commit with a message in
the form the AGENTS.md file describes. Do not push.

3. Read what it did, before anything else

  • Which files did it touch? It should be one. If it “tidied” something else, undo that.
  • Is the branch name sensible, and are you on it?
  • Does the commit message carry the right form?

4. Push, and open the pull request yourself

Push from Antigravity or from GitHub Desktop, then open the pull request on GitHub. Fill in the template, including the AI-Assisted line: 

AI-Assisted: Antigravity / wrote the table row and the commit message /
I fixed the role, which it guessed wrong

Then the same as Route A: a teammate reviews, and the reviewer merges.

What the agent must never do for you: open the pull request, approve it, merge it, or create a phase tag. Those are the acts the marks are read from. An agent doing them is the one thing that makes a repository unreadable as evidence of who did what.

What to install — Windows

Windows 10 or 11, 64-bit.
WhatWhyWhere
Google Antigravity Where you build. It also drives GitHub and the database for you. antigravity.google/download
Git for Windows The program underneath everything else. Install it before Antigravity, and accept the defaults. git-scm.com/download/win
GitHub Desktop Buttons instead of typed commands, for the loop. This is what the walkthrough screenshots show. desktop.github.com
Google Chrome What the class demonstrates in, and what your own page is checked in. google.com/chrome
  • Install in that order — git first. If Antigravity cannot find git, it will say so when you try to commit, and reinstalling git fixes it.
  • You need nothing else. No Node, no Python, no database on your laptop. This course has no build step: the pages you write are opened directly, and the database lives in Supabase.
  • If your laptop cannot run Antigravity, say so. There is a browser-only route through the whole course with the same deliverables and the same marks.
